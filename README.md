# Mini Enigma - Backend

API REST en Node.js, Express y MongoDB para la aplicación de cifrado y descifrado Mini-Enigma. 

El proyecto maneja usuarios, autenticación y los distintos algoritmos de cifrado de la app.

> **Nota:** Este repo tiene errores intencionales distribuidos en distintos endpoints y módulos para la clase de testing y depuración.

## Requisitos

* Node.js (v18 o superior)
* MongoDB corriendo en local (puerto por defecto 27017) o una URL de Mongo Atlas
